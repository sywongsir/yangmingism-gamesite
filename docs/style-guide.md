# 風格指南（style-guide）

全站視覺的唯一標準是序章動畫短片（附件二）。風格名稱：**宣紙水墨 × 長夜燈火**。參考影格存於 `style_ref/`（檔名 `fSSSS.S.webp` 為影片秒數），情緒板見 `style_ref/moodboard.webp`。

## 1. 色板（取樣自短片）

| 組別 | 變數 | 色值 | 用途 |
|---|---|---|---|
| 宣紙 | `--paper-50` 至 `--paper-300` | #E5DDCB #DAD1C1 #CAC1B0 #ACA497 | 紙面版面、卡牌底、教師面板 |
| 墨 | `--ink-900` 至 `--ink-300` | #0C0B0B #242322 #3B4145 #585551 #847F77 | 正文、主要按鈕（濃墨筆刷） |
| 長夜 | `--night-950` 至 `--night-500` | #07090B #161C20 #262F35 #384650 #4B5963 #506173 | 夜色版面、工具列、字幕列 |
| 月 | `--moon` | #D3C5B7 | 月光、淡框線 |
| 燈火（唯一強調色） | `--lamp-300` 至 `--lamp-600`、`--ember`、`--flame-core` | #F4D9A2 #F4CB99 #EDC089 #E7BD73 #D6915D #FD7108 | 焦點、得分、進度、徽章金邊 |
| 青綠 | `--jade-*`、`--leaf` | #234D57 #2C4042 #3B5C4F #496564 #4C764F | 竹林、安全提示 |
| 袍褐 | `--robe-*` | #685A4E #857465 #A4917E #BCAC99 | 人物、香枝、次要裝飾 |
| 字幕 | `--subtitle` | #F3EEE4 | 故事字幕（與短片字幕同色） |

原則：燈火金是全站唯一的強調色；不用紅色表示扣分或錯誤（扣燈油用「燈火搖曳變暗」）。夜色版面的文字一律用米白（對比 > 12:1），紙面版面的文字一律用濃墨（對比 > 11:1）。

## 2. 字體與排版

| 用途 | 字型 | 後備 |
|---|---|---|
| 中文正文、故事字幕 | Noto Serif HK（香港字形明體） | Noto Serif TC → Source Han Serif TC → PMingLiU → serif |
| 標題、遊戲名、卡牌名 | LXGW WenKai TC（霞鶩文楷 TC） | Noto Serif HK 粗體 |
| 英文副標、英文字幕 | EB Garamond（斜體） | Georgia → serif |

字型經 Google Fonts 載入（`display=swap`），並在頁面載入完成後才請求（最遲 3 秒），首屏先用後備字型；Noto Serif HK 只載入 400 字重，粗體由瀏覽器合成。斷網時自動用後備字型，網站照常運作。簡體模式另載入 Noto Serif SC（400）。霞鶩文楷 TC 的「為」字是「爲」的字形，不合香港字形，所以另外自託管一個只含「為」字的 Noto Serif HK 子集（`assets/fonts/hk-fix-*.woff2`，約 1KB，OFL 授權），以 `unicode-range` 覆蓋此字。

字級以 `--fs` 隨視窗縮放：1920×1080 投影時根字級約 28–30px；課堂模式在 1600×860 以上的螢幕，情境卡、案件說明、解說、預告、突發事件、解碼文件、講解及案例卡等主要內文以 `max(1rem, 28px)` 保證不小於 28px（`css/components.css` 末段）；平板不小於 18px；「投影放大」開關再放大 1.25 倍。標題字距 0.04–0.14em。

網站標題排法取材短片 114 秒：米白字、金色外光（`text-shadow` 兩層），下方一道由左至右展開的橫向光線，周圍金色微塵漂浮。所有中文都用網頁字型排字，圖像內不放任何文字。

## 3. 元件

| 元件 | 樣式要點 |
|---|---|
| 主要按鈕 | 一抹濃墨筆刷（不規則圓角＋細纖維紋），滑過時燈火金外光；觸控目標 ≥ 48px |
| 次要按鈕 | 淡墨線框，不規則圓角 |
| 卡牌 | 宣紙底（SVG feTurbulence 雜訊＋紙紋 WebP），內陰影暈邊，四角輕微不規則 |
| 卡背 | 雲紋（夜藍）或竹紋（青綠） |
| 面板 | 夜色半透明（`panel-night`）或宣紙（`panel-paper`），邊緣以大範圍柔和陰影「暈開」 |
| 燈站 | 發光圓框（取材 97 秒金色光環），三態：未點亮（灰階、淡墨框）、進行中（燈火搖曳、光暈呼吸）、已完成（全彩、金框） |
| 徽章 | 圓形水墨印章，中央為該節意象墨線圖示，名稱以網頁字型疊加 |
| 計時器 | 「燃香」：香枝隨時間縮短、頂端火點、運行時冒煙；最後 10 秒脈動；可拖放到四角 |
| 組別列 | 每組一盞燈，燈油量＝火光大小；按組號固定排列，不排名 |
| 字幕列 | 底部黑帶，中文 #F3EEE4、英文較小斜體，與短片字幕一致 |
| 圖示 | 全部是自繪墨線 SVG（`ui.js` 的 `ICONS`），不用表情符號 |

## 4. 動態

| 動態 | 規格 |
|---|---|
| 墨暈轉場 | Canvas 繪製的墨滴由點擊處擴散覆蓋（約 1000ms），換層後由中心向外褪去（約 800ms） |
| 鏡頭推進 | 主頁 `transform` 縮放 1.7 倍加平移至燈站，約 900ms，再接墨暈轉場；關閉時反向 |
| 視差 | 主頁 6 層（遠山、月光、遠霧、山路、近霧、前景山石），滑鼠或陀螺儀驅動，深度 4–26px |
| 雲霧 | 兩層霧帶以 120 秒和 190 秒循環反向漂移 |
| 金色微塵 | Canvas 粒子，主頁 46 粒上限；分層開啟時停止 |
| 加分 | 燈油滴由來源飛入該組燈（約 800ms），燈火 `bloom` 一下 |
| 扣分 | 燈火搖曳變暗（`dimming` 1.2s），不用紅色、不用警告音 |
| 重來卡 | 燈火回復，畫面「墨跡倒流」（模糊再清晰） |
| 揭曉 | 金光迸發（放射光線＋光核＋微粒），取材短片 53–54 秒 |
| 毛筆化火 | SVG 筆劃描寫後轉金，筆端長出火焰，取材短片 21–24 秒 |
| 減少動態 | `prefers-reduced-motion` 或教師控制台「動畫強度：減少」時，所有動畫改為 0.3 秒淡入淡出；墨暈轉場改為淡入淡出 |

只用 `transform` 與 `opacity` 做動畫；沒有任何每秒超過 3 次的閃光。

## 8. 第5、6節的專屬元件（第四階段）
- **根脈樹**（第5節）：深色根脈影格上四條樹根，樹根卡貼上後該條根亮起琥珀光（`--lamp-400` 外光暈）；葉數以綠葉點（`--leaf`）長在樹冠，達標換成長葉影格。
- **玉符契合測試儀**（第5節）：兩半玉符（`--jade-*`）按「相同／不同／條件」靠近、留縫或以絲繩繫住，契合度 1–3 星；不判對錯。
- **補充貼紙**：同意／補充／質疑三色圓點貼紙，只有「補充」計分。
- **同心圈**（第6節）：SVG 七圈（我、家、學校、社區（香港）、國家、世界、自然），每圈配 24×24 線條圖示；選取時圈帶染淡金，墨霧牆（高斯模糊墨團）在寫出化解方法後化成金色橋板；結算時金圈由內至外逐層亮起（每圈延遲 0.35 秒），減少動態時直接顯示。
- **漣漪拼圖**：排對一行即多擴一圈漣漪並標上「關心的範圍」。
- **步驟條**：手冊六步，完成的步驟以玉綠圓點標示，步驟五、六以虛線框標「課後」。
- **承諾信封與簽名板**：沿用第3節信封（封蠟、翻蓋動畫）；簽名板為 canvas 手寫，墨色 `--ink-800`；開封頁未到期時顯示封蠟信封及倒數。
- **終章**：七幕交疊淡入（每幕緩慢推鏡 `fin-kb`），字幕置於畫面下方三分之一，中文霞鶩文楷、英文 EB Garamond 斜體，與序章字幕一致。

## 9. 列印教材（第五階段）
列印教材頁 `#/lN/print` 的畫面和列印樣式都在 `css/print.css`，排版程式在 `js/lessons/print.js`，文字在 `js/content/print.js`。
| 項目 | 規格 |
|---|---|
| 紙張 | 以具名 `@page` 指定：`pa4`（A4 直向）、`pa4l`（A4 橫向）、`pa5`（A5）、`pa3`（A3），邊界 0，由頁面內留白控制 |
| 底色 | 宣紙米白 #FFFDF8（`print-color-adjust:exact`）；列印時要勾選「背景圖形」才會印出底色及淡色底紋 |
| 文字 | 標題霞鶩文楷，內文 Noto Serif HK；墨色 #1B1D1F，次要文字 #3B4145，小字 #6B665F（符合 4.5:1 對比） |
| 強調色 | 琥珀線 #A67952、深赭 #765339，只用於標題線、編號及印章，大面積不用金色以節省墨水 |
| A4 卡牌 | 每頁 8 張或 4 張，卡與卡之間是灰色虛線（#A39C90）裁切線，頁底印「✂ 沿虛線裁切」 |
| A5 產出卡 | 一頁一張，書寫線為點線，間距 7mm；字多的卡（第6節行動承諾卡）用 `.tight` 緊湊版面（6mm） |
| A3 海報 | SVG 繪製（志燈牆、良知鏡、知行橋、煉鋼爐、根脈樹、同心圈），外框雙線，所有字都在外框內 |
| 頁尾 | 每頁右下印「心學心傳．古為今用｜第N節《遊戲名》」及教材名，不印學校資料 |
| 畫面縮圖 | 以 `zoom` 縮小真實頁面作預覽：A4 0.27、A4 橫向 0.24、A3 0.19、A5 0.38 |
| 簡體 | 開啟簡體時，列印內容（包括 SVG 海報文字）同樣轉換 |
