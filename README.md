# 心學心傳．古為今用

初中價值觀教育互動遊戲網站（中三，6 節 × 40 分鐘）。純靜態網站：不需 build、不需伺服器、不需資料庫；雙擊 `index.html` 亦可離線使用。

> 目前進度：**全部五個階段已完成**——全站框架、主頁「長夜山河圖」、序章、單元總覽、來源與說明、我的回顧盒、教師控制台、終章，以及第1節《龍場闖關》、第2節《良知偵探社》、第3節《知行橋工程隊》、第4節《煉鋼爐》、第5節《根脈解碼局》、第6節《同心圈》（均有課堂模式與自學模式），另有第6節開封跟進頁；第五階段完成六節列印教材頁、一鍵繁簡切換、效能優化及全站驗收（結果見第十節）。

## 一、部署

**Netlify**：登入後新增網站，選「手動部署」（Deploy manually），把整個 `xinxue-site` 資料夾拖進去即可；或連接 GitHub repo，Build command 留空，Publish directory 填「.」（根目錄）。

**GitHub Pages**：建立 repo（如用免費帳戶，repo 須設為公開）→ 上載資料夾內所有檔案到根目錄（保留 `.nojekyll`）→ Settings → Pages → Source 選「Deploy from a branch」→ 分支 `main`、資料夾 `/(root)` → 儲存，等一至兩分鐘取得網址。

GitHub 單一檔案不可大於 100MB；本網站最大的檔案是序章影片 `assets/video/prologue-web.mp4`（約 14.5MB，已壓縮至 15MB 以下），整個資料夾約 25MB，可直接上載。

**離線備課**：雙擊 `index.html`（file://）即可。斷網時字型會改用電腦內的後備字型，其餘功能不受影響。

提醒：repo 名稱、Netlify 網址和 GitHub 帳戶名都會出現在網址中，請用不含學校資料的中性名稱。

**修改內容**：只改 `js/content/*.js` 的文字；修改班級設定：改 `js/config.js` 或用教師控制台。改完重新上載即可，不需編譯。（`tools/` 內只有繁簡對照表產生程式，網站運作不需要它，見第七節之二。）

## 四、修改文字內容

所有中文內容（故事、卡牌、選項、提問、參考答案、教師回饋、注意事項、提示）只寫在 `js/content/`：`common.js` 是全站共用文字，`l1.js` 至 `l6.js` 分別是第1至6節（每個檔案末段的 `verify` 是待核對清單，只作備課紀錄，網站任何頁面都不會顯示；`teacherNotes` 是教師備註）。程式邏輯在 `js/lessons/`，一般不用改動。用任何文字編輯器打開，修改引號內的文字後存檔即可，不用改動程式。請保留標點和引號，修改後重新整理網頁。

## 五、班級設定

最簡單的方法是在網站的「教師控制台」修改（全班人數、組數、組名、各節全班目標、預設模式、動畫強度、教師密碼），設定只存於該部電腦的瀏覽器。如要改預設值（例如派發給其他老師），修改 `js/config.js`。

組名請用「第一組」等中性名稱，不要用學生姓名。

各節「全班目標」留空（`null`）時的預設：第1節志燈 32 枚；第2節「良知鏡重圓」＝三種良知碎片（惻隱、是非、羞惡）全班各集齊至少 1 塊；第3節「知行橋貫通」＝組數 × 3 塊橋板（預設 8 組即 24 塊）；第4節「百煉成鋼」＝組數 × 輪數 × 3 × 70%（預設 51）；第5節「根脈樹長葉」＝組數 × 3 片葉（預設 24）；第6節「同心圈亮起」＝全班人數 × 80% 面小旗（預設 32 人即 26 面）。在教師控制台填上數字即可覆蓋。

## 六、私隱

網站不設登入、不收集姓名、不上傳任何資料；不用 cookie、分析或追蹤。學生在自學模式的輸入只存於該裝置瀏覽器（localStorage），可在「我的回顧盒」匯出備份檔或清除。課堂模式的投影畫面只顯示老師輸入、已過目的內容。

### 七之二、一鍵繁簡切換
首頁頂欄右上角（及首次到訪對話框）有「简体」按鈕：按一下，全站介面、故事旁白、卡牌、選項、提問、教師面板、回顧盒及列印教材（包括海報上的字）即時轉為簡體；再按「繁體」還原。選擇存於該部電腦的瀏覽器，下次開啟沿用。轉換只改畫面顯示，不改內容檔；學生在輸入框內打的字、回顧盒存檔及匯出的 CSV／JSON 都保持原本輸入，不作轉換。英文字幕不受影響。

對照表 `js/core/hans-dict.js`（約 28KB）由 `tools/build-hans.py` 以 OpenCC 字典（Apache-2.0 授權，HKVariantsRev、TSCharacters、TSPhrases）產生：收錄全部繁簡單字對應，另收網站文字用到、逐字轉換會出錯的詞組。簡體模式另載入 Noto Serif SC（SIL OFL）以顯示簡體字形。轉換以字表為主，個別詞語未必合內地用語習慣（例如不會把「巴士」改為「公交车」）。如日後修改了內容文字，可在網站根目錄執行 `pip install opencc-python-reimplemented` 及 `python3 tools/build-hans.py` 重新產生對照表（不執行亦可運作，只是新詞組按逐字轉換）。

### 七之三、效能
字型在頁面載入完成後才向 Google Fonts 請求（最遲 3 秒），首屏先以電腦內的後備字型顯示，之後換上網頁字型；Noto Serif HK 只載入 400 字重，粗體由瀏覽器合成（可變字型連 700 字重約 1.2MB）。第2至6節及列印的樣式表改為非阻塞載入，各節的內容檔與程式檔並行下載，主頁預載第一張霧層圖。

## 八、待核對事項

按第五階段的要求，網站所有頁面（包括教師面板、教師備註、來源與說明、列印教材）都不顯示任何「待核對」提醒；完整清單只放在 `docs/待核對事項.md`，供老師備課時自行核對。清單內容見 `docs/待核對事項.md`（第5節另有：三份解碼文件需對照官方文本、民惟邦本／民為邦本用字、配對二三的依據、示範報告及詞彙表為自撰；第6節另有：張載《西銘》、陽明《大學問》及孟子原文、人類命運共同體的官方表述、不忍度說明為自撰、教育局手冊六步名稱；第4節另有：《傳習錄》原話、手工咭／手工咖、自學單人決策版自撰選項、時間分配與概要表不同等）。主要包括：少年陽明「人生第一等事」的對話、格竹細節、龍場處境與悟道細節及揭曉卡文字（均待核對《王陽明年譜》）；「志向三問」與「燈油三線索」屬教學設計。第2節：孟子《公孫丑上》孺子入井及「四端」原文、陽明「一體之仁」相關原文、良知雷達只列三項的簡化說明。第3節：陽明論知行合一的原話及出處（《傳習錄》）、「知而不行，只是未知」的原典對應文句。各節的裂縫卡、橋板、塵埃卡、良知碎片等均屬教學設計，計劃書內不要寫成陽明原話。旁白英文為輔助翻譯，亦列入清單待核對。

## 九、第一階段的判斷與已知限制

1. **志燈牆目標**：照提示詞預設 32 枚。由於預設 8 組 × 起始 5 點＝40 枚，開課時已達標；網站照樣保留「長夜點亮」作全班慶祝（本節不設勝負）。如希望目標更具挑戰，可在教師控制台調高（例如 60）。
2. **「為」字字形**：霞鶩文楷 TC 的「為」顯示成「爲」，不合香港字形；已自託管一個只含此字的 Noto Serif HK 子集作覆蓋。
3. **影格內文字**：短片部分影格有字幕或書法字，已裁去或用紙紋覆蓋，畫面文字一律以網頁字型疊加。
4. **環節編號**：第1節六個環節的網址為 `s0`（夜行令）至 `s5`（志燈牆結算）。
5. **背景音樂**：預設沒有；音效全部程式合成，不需音檔。
6. **列印教材頁**：已於第五階段完成六節（見九之五）；各環節內亦可直接列印產出卡，以及在教師面板列印教師觀察表、匯出 CSV。
7. **自託管字型子集**（P1）：第五階段決定不全面自託管（中文字型檔太大），改為延遲載入並只載 400 字重（見七之三）。

## 九之二、第二階段：第2、3節玩法與判斷
**第2節《良知偵探社》**（全班目標：良知鏡重圓）
1. 第一反應：情境「小孩跌倒、無人停下」，全班舉反應牌，課堂模式只用墨點顯示人數，不評論、不排名；自學模式私下選牌，只存本機。
2. 古案「孺子入井」：動機鑑定——把三張現場線索卡拖放（或點選）到最吻合的動機嫌疑卡下，再說明推理；推理有線索支持即得良知碎片一「惻隱」。揭曉時以手觸水面、漣漪兩個影格說明「不忍之心」。
3. 現代三案（虛構）：案件A教室一角、案件B群組風波（網頁繪製的虛構介面）、案件C地鐵一刻，可由老師平均分配。各組依次完成第一念、良知雷達、塵埃卡、換位卡、清塵行動（想一個「最小援手」，擦去鏡上塵埃）。說出案件哪裡不對並完成雷達，得碎片二「是非」；完成塵埃卡分析並寫出自己最可能被哪一張擋住（可寫不讀），得碎片三「羞惡」。所有得分均可撤銷。
4. 良知時刻卡：句式支架填寫，可匯出 PNG、列印或存入回顧盒；兩人互相配對分享。
5. 良知鏡結算：三種碎片集齊後，鏡面裂痕合攏、水面滿月亮起（goal 動畫「良知鏡重圓」），然後頒發敏銳偵探、暖心偵探、清塵偵探徽章，三句總結及離場券。

**第3節《知行橋工程隊》**（全班目標：知行橋貫通）
1. 知行投票：5 句「知道應該」的事，全班按常常／有時／很少匿名舉牌（老師用增減器輸入人數）；裂縫地圖自動標出落差最大的兩項。
2. 真假知行：10 秒搶答，揭曉後答對組蓋「真知章」（章不計入橋板）；自學模式 5 題答對 4 題或以上，自動獲「真知者」。之後以墨筆書寫動畫寫出「知行合一」。
3. 知行橋工程：三張情境卡可平均分配或點選改派。各組先選兩張裂縫卡（對應裂縫發金光），再寫三塊橋板（第一步、求助對象、完成標記），每塊 +1；橋板落入裂縫後變成金色接縫。「測試員」只提示籠統詞，不阻止提交。之後 20 秒及 40 秒排練、上台演出，其餘組舉穩度牌（1 至 3 星，只顯示平均）。教師歸納時可加「補充橋板」。
4. 承諾挑戰：知行對照表（可用墨圈圈出落差）→ 承諾欄（太大會提示拆細）→ 橋板三問互檢 → 封存承諾。
5. 橋通結算：橋板達標後，橋上人物由知岸走到行岸，觸發「知行橋貫通」動畫；頒發真知者、築橋者徽章，三句總結及離場券。

**承諾信封**：在第3節按「封存」後，承諾以封存信封的形式存入「我的回顧盒」，盒內只顯示信封，不顯示內容，草稿同時清除；第4節開首的開封環節才會打開（見下文九之三）。課堂上亦可列印信封內頁，讓學生手寫後放入實體信封。守約者徽章按大綱在第4節開封時才頒發。

**判斷與已知限制**
1. 第2節良知雷達只列惻隱、是非、羞惡三項（孟子四端還有辭讓），照大綱配合仁愛主題的簡化，已列入待核對。
2. 第3節的穩度牌只顯示全班平均星數，不顯示個別組排名，以符合「不排名」原則。
3. 第3節演出環節在自學模式改為「寫一句對白並自評」。
4. 時間不足時，老師可在教師面板直接觸發 goal 動畫，徽章可留待下一節開首頒發。

## 九之三、第三階段：第4節玩法與判斷
**第4節《煉鋼爐》**（全班目標：煉鋼爐溫度計達「百煉成鋼」）
1. 開封（3 分鐘）：課堂模式由老師示範拆信，畫面列出自評、分享、守約章三步；守約者只用增減器輸入人數（不記名字），可播放蓋章動畫。自學模式讀取回顧盒內第3節封存的信封：按「拆開信封」後封蠟脫落、信紙升起，承諾內容以信紙顯示；圈選完成／部分完成／未完成並寫一句原因；選「完成」即蓋守約章、得「守約者」徽章；未完成不扣分，改寫「橋哪裡要加固」。回報與承諾一併存回回顧盒，信封卡會顯示封存時間及第4節開封時間。沒有信封（例如換了裝置）的同學可以補寫承諾再回報，存入第4節回顧盒。
2. 事上磨煉是什麼（4 分鐘）：陽明伏案影格加爐火一閃帶出「人須在事上磨，方立得住」；小明／小美兩張對比卡（課堂舉手表決後揭曉）、解說與「學游泳」比喻、煉鋼三問及遊戲規則。
3. 煉鋼挑戰（20 分鐘）：三張任務卡 A「班際閱讀分享日」、B「校園環保行動週」、C「社區關懷小行動」（可平均分配或點組名改派）；初步計劃五欄、預算 300 元；教師面板可抽各輪觀察員（每組每輪不同組員，會帶出隨機角色名稱）。三輪突發事件：輪一缺席卡（觀察員的角色臨時缺席）、輪二分歧卡（兩張立場卡要按住才顯示，放手即蓋回；輪後全組按「脫角」）、輪三失誤卡（預算 300 → 150 裂幣動畫；每組一張回爐卡，可重做 2 分鐘）。每輪觀察員按三個承擔指標勾選，每勾一格 +1 鋼度、錘子打一下鋼條並濺出火星；**每輪最多 3 分**，老師的 +1／−1 也會自動歸入當輪的下一個指標，滿 3 分時提示並拒絕。鋼條顏色隨鋼度由暗灰→暗紅→橙→金→金白。分享頁按組號固定排列，不排序。
4. 磨煉日誌（8 分鐘）：日誌四欄＋句式支架（可存入回顧盒、匯出 PNG、列印）；「我看見你」讚賞卡，如果只寫「很棒」「加油」等籠統詞，會溫和提示補上一個具體行為（不阻止儲存）。
5. 煉鋼爐結算（5 分鐘）：溫度計升到目標後鋼條燒至金白、火星四濺，再冷卻成青鋼，觸發「百煉成鋼」動畫；頒發補位者、調解者、收尾者（畫面附依觀察員記錄的參考建議；守約者已在開封時頒發），三句總結及離場券。
6. 時間不足：教師面板「時間不足」提供三種做法——三輪照做、輪二輪三合併、略過輪二；合併或略過時全班目標自動按 2 輪重算。
7. 自學模式「單人決策版」：學生擔任統籌，每輪一題選擇題（選後顯示解說及參考答案）＋短答，再按三個承擔指標自我檢查（每輪最多 3 分，全課 9 分，達 7 分即百煉成鋼）。
**判斷與已知限制**
1. **任務 C 名稱**：提示詞寫「手工咖」，大綱寫「手工咭」；按大綱用「手工咭」，已列入待核對。
2. **每輪 3 分封頂**：除了勾選表，老師用 +1 加分亦會封頂，以免意外超出大綱「每輪最多 3 分」的規則；−1 會取消當輪最後一個指標。撤銷可完整還原。
3. **全班目標**：大綱只寫「全班滿分的七成」，網站以「組數 × 進行輪數 × 3 × 70%」向上取整（8 組三輪＝51；合併或略過＝34），可在 `js/config.js` 或教師控制台改。
4. **自學單人決策版的選項與解說**為網站自撰（大綱只寫「單人決策版」），只作提示，不影響計分；已列入待核對。
5. **守約者**在課堂模式只記人數，不記名字，以符合私隱原則；自學模式則照常頒給本人。
6. **時間分配**：大綱詳細流程為 3＋4＋20＋8＋5 分鐘，網站依此設定各環節計時器。
7. 「人須在事上磨，方立得住」一句取自序章 69–71 秒字幕，原文出處待核對《傳習錄》。
8. 修正共用元件：`ui.h` 的 style 物件現可設定 CSS 自訂屬性（`--xx`），連帶令第1節便利貼的微傾角度、第3節穩度牌的部分星數正確顯示。
## 九之四、第四階段：第5、6節、開封跟進頁與終章
**第5節《根脈解碼局》**（全班目標：根脈樹長葉）
1. 根脈樹（5 分鐘）：深色根脈影格上，各組把立志、良知、知行合一、事上磨煉四張樹根卡拖放（或點選）到樹根位置，每貼一張該條樹根亮起琥珀光；可寫「我在今天哪裡見過類似的想法」（可不寫）；宣布遊戲「文化解碼員」。
2. 解碼任務（8 分鐘）：先顯示來源說明（官方論述與學者詮釋，先了解再檢驗，不要求表態），再以拼圖閱讀三份文件（可逐份展開，附詞彙表），寫解碼卡「兩個結合就是……」。自學模式寫到「契合」及「互相成就／有機結合／新的文化生命體」其中之一，即蓋「解碼成功」印並得一片葉；未寫到會提示重讀文件二。
3. 契合測試（15 分鐘）：三張配對卡（民惟邦本—以人民為中心；知行合一—重視實踐；天人合一—人與自然和諧共生）配合契合三問與「契合測試儀」寫契合報告（相同／不同／條件，契合度 1–3 星；玉符「契合測試儀」隨答案靠近或分開），完成 +1 葉；驗證站讓其他組貼同意／補充／質疑貼紙，每張「補充」+1 葉（可撤銷）；教師歸納。
4. 質疑與思辨（7 分鐘）：質疑卡（自學可寫可不寫）、思辨圈立場牌（全班人數只以匿名墨點顯示分佈，不計分），教師總結「精神相通不等於直接來源」。
5. 根脈樹結算（5 分鐘）：葉數達標後樹冠長滿綠葉，觸發「根脈樹長葉」動畫；頒發解碼員、契合分析師、提問勇士；三句總結；離場券連同解碼卡、契合報告存入回顧盒。

**第6節《同心圈》**（全班目標：同心圈亮起）
1. 一體階梯（5 分鐘）：回顧孺子入井後，逐張展示幼童、哀鳴的鳥、折斷的草木、破碎的瓦石四卡，全班按不忍度 1–3 舉牌（只以墨點顯示人數；自學可選「與我無關」）；之後以墨圈講解「一體之仁」與四種隔閡。
2. 脈絡拼圖（8 分鐘）：先顯示來源說明，再把孟子、張載、陽明、今日論述四張概念卡依時間排列，並配上「關心的範圍」詞條；每排對一行，漣漪多擴一圈（支援模式顯示圖像和關鍵詞）；教師講解及「相通不等於來自」圖解。
3. 同心圈任務（10 分鐘）：全班抽卡（三個虛構案例平均分配，隨機派隔閡卡；自學單抽或自選）；任務單點選受影響的圈層（七圈：我、家、學校、社區（香港）、國家、世界、自然），為每圈寫「我可以……／一起做的人是……」，再寫化解隔閡的方法，墨霧牆會被橋板化開；可再抽第二張隔閡卡。團結值：具體合作方式最多 3 分＋化解隔閡最多 2 分（每組最多 5 分，教師 +1 亦封頂，可撤銷）。自學會讀取第3節橋板作為提示。匯報後教師總結。
4. 行動承諾（12 分鐘）：手冊步驟一至四。自我評估會列出回顧盒中第1至5節的紀錄（含第3節橋板），點一下即貼入第一欄；行動承諾卡自動帶入第1節志向，選「我的同心圈」時至少要連到社區、國家、世界或自然其中一圈；承諾三問互檢；簽署（化名或縮寫，可用手寫簽名板）並設定開封日期（預設兩星期，可選三星期）後封存，信封存入回顧盒，草稿只保留圈層供插小旗。
5. 同心圈結算（5 分鐘）：課堂由老師按七圈輸入小旗數，達標後金色同心圈由內至外逐層亮起，觸發「同心圈亮起」；頒發同心者、破隔者、築夢者；提問、三句總結、離場券，並可播放單元終章或前往開封跟進頁。

**開封跟進頁 `#/l6/open`**：開封日期前信封鎖著並顯示倒數；教師可按「提早開封（教師）」作示範（需確認）。到期後拆開信封，承諾內容與簽名重現，學生選自評（完成／部分完成／未完成），寫步驟五「實踐及行動」紀錄及步驟六三問，存回回顧盒（草稿會自動保存；不計分）。換了裝置沒有信封的同學可補寫承諾再跟進。回顧盒內的第6節信封有「前往開封跟進頁」按鈕。

**單元終章 `#/finale`**：照提示詞第6節所列次序——白鶴與青綠山水 → 城市 → 夜山燈火（「立志、良知、知行合一、事上磨煉……」）→ 學生捧燈（「這盞燈，如今傳到你手中。」）→ 燈河（「你的志向是什麼？你將如何踐行？」）→ 標題以金光橫線與微塵浮現 → 一盞燈「此心光明，亦復何言。」→「回到山河圖」「打開我的回顧盒」。字幕照抄短片中英字幕；可略過；減少動態時縮短至約 14 秒。

**判斷與已知限制**
1. **用字**：第5節配對一按提示詞說明統一用「民惟邦本」（大綱概要表及短片樹根寫「民為邦本」），在教師備註說明；第6節承諾例子中的「手工咭」沿用第4節判斷。
2. **素材**：第5、6節全部取自短片 76–112 秒影格，只裁去字幕及以程式去除畫面字，沒有新增 AI 生成圖像。一體階梯的「井邊幼童」沿用短片漣漪中的孩童影格；脈絡拼圖卡的圖像亦沿用現有影格。
3. **自撰內容**（已列入待核對）：第5節自學示範報告、詞彙表；第6節不忍度說明、自學模式的部分提示句。
4. **來源說明**：第5節進入時以對話框顯示來源說明，每個瀏覽階段（課堂／自學各一次）只自動彈出一次，以免每次重新整理都打斷；解碼任務的「來源說明」環節及第6節的「來源說明」環節則每次都會顯示。
5. **承諾私隱**：封存後草稿中的承諾內容即清除，只保留所選圈層（用來插小旗）；課堂模式不顯示個別學生的承諾，小旗只顯示圈層，不顯示內容；不評價承諾的「愛國程度」。
6. **提早開封**：提示詞要求開封日期前信封鎖著；為方便課堂示範及特殊情況，加設需確認的「提早開封（教師）」，回顧盒會記錄為提早開封。
7. **團結值封頂**：除自學自動計分外，老師的 +1 亦受「合作 3＋化解 2」封頂，滿分時提示並拒絕；撤銷可完整還原。

## 十一、已知限制與建議的下一步
**已知限制**
1. 未在實機 iPad Safari 上測試（已用 WebKit 引擎模擬）；手寫簽名板、拖放等觸控操作建議上線後用學校 iPad 試一次。
2. 學生資料只存於該裝置的瀏覽器；換裝置、用無痕模式或清除瀏覽資料都會遺失，須用回顧盒「匯出備份檔」保存。第3節信封到第4節開封、第6節信封到開封跟進頁，都要用同一部裝置及瀏覽器。
3. 網頁字型由 Google Fonts 提供；學校網絡如封鎖 Google，會改用電腦內的後備字型，外觀稍有不同，功能不受影響。
4. 繁簡切換以字表轉換為主，個別詞語未必合內地用語習慣。
5. 部分資訊較多的環節（例如第4節三輪挑戰、第5節契合測試、第6節講解）在 1920×1080 投影時要在舞台內捲動。
6. 英文副字幕、自撰內容和待核對事項仍須老師核對（見 `docs/待核對事項.md`）。

**建議的下一步**
1. 按 `docs/待核對事項.md` 核對原文、官方表述和英文字幕，在 `js/content/*.js` 修改。
2. 部署到 Netlify 或 GitHub Pages 後，在課室投影機和 iPad 上各試行一節，確認字體大小與觸控操作。
3. 試教後按學生反應，在教師控制台調整全班目標、組數和動畫強度。
4. 如學校網絡封鎖 Google Fonts，又需要字型完全一致，可考慮自託管中文字型子集（約增加 2–4MB）。
